# Porsche Sales Intelligence

Projeto de análise e visualização de dados de vendas de veículos Porsche, com foco em Business Intelligence, qualidade de dados e indicadores de desempenho comercial.

O projeto utiliza Python para limpeza e padronização de dados a partir de regras definidas em um schema, gerando uma base estruturada para alimentar uma dashboard interativa desenvolvida com HTML, CSS e JavaScript.

## Funcionalidades

- **Tratamento de dados:** padronização de datas, valores monetários, modelos, quilometragem e informações comerciais.
- **Dashboard interativa:** visualização de indicadores e gráficos com atualização dinâmica.
- **Filtros:** vendedor, modelo Porsche, cidade e método de pagamento.
- **KPIs:** faturamento total, veículos vendidos, ticket médio e cidades atendidas.
- **Análise comercial:** ranking de vendedores por faturamento e modelos mais vendidos.
- **Insights regionais:** identificação dos modelos de maior demanda em cada cidade.

## Tecnologias

- Python e Pandas — tratamento e transformação de dados
- Excel — armazenamento da base de dados
- HTML5 — estrutura da dashboard
- CSS3 — interface responsiva e identidade visual
- JavaScript — interatividade, filtros e cálculos dinâmicos

## Objetivo

Transformar dados comerciais brutos em informações claras e acionáveis, facilitando a identificação de tendências de vendas, oportunidades de mercado e desempenho da equipe comercial.

*Projeto independente, desenvolvido para fins de estudo e portfólio, sem vínculo oficial com a Porsche.*
